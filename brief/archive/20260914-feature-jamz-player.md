## Overview

建立名為 **Jamz Player** 的原生 iOS MP3 播放器，支援 HTTPS 下載至手機、離線播放、循環播放、睡眠定時器，以及 MP3 ID3 歌曲資訊與封面顯示。

第一版以 iPhone、iOS 17 以上為目標，使用 SwiftUI 設計介面，搭配 Apple 原生音訊、下載與本機儲存能力。介面採繁體中文、深色背景與暖橘色重點，包含音樂庫、網址匯入面板、底部迷你播放器與完整播放畫面。

目前專案為空。此提案只規劃開發；目前選用的開發工具路徑為 Command Line Tools，實作時需確認完整 Xcode 與 iOS Simulator 是否可用。編譯、模擬器介面驗證及實機背景播放驗證分別記錄，不以程式碼檢查代替執行結果。

## Scope

- `JamzPlayer.xcodeproj/`：建立可由 Xcode 開啟的 iOS App 專案、測試目標與背景音訊設定。
- `JamzPlayer/App/`：App 入口、共用狀態與依賴組裝。
- `JamzPlayer/Models/`：歌曲、本機檔案索引、循環模式與定時器狀態。
- `JamzPlayer/Services/`：HTTPS 下載、本機儲存、ID3 讀取、音訊播放、睡眠定時與鎖定畫面控制。
- `JamzPlayer/Views/`：音樂庫、匯入面板、迷你播放器、完整播放器及共用視覺元件。
- `JamzPlayer/Resources/`：色彩、App 圖示及缺少專輯封面時的預設圖像。
- `JamzPlayerTests/`：儲存、資訊回退、循環與定時邏輯的必要測試及測試素材。
- `README.md`：建置、執行、匯入方式及模擬器／實機驗證步驟。

本次不包含串流平台整合、帳號、雲端同步、ID3 編輯、自訂播放清單與 App Store 發佈。HTTPS 匯入以可直接下載 MP3 的網址為範圍，不解析一般網頁中的音樂。

## Requirements

- [V] R1：建立顯示名稱為 Jamz Player 的原生 iOS 專案，支援 iOS 17 以上 iPhone，提供繁體中文介面。
- [V] R2：使用者可貼上 HTTPS MP3 直連網址下載，查看進度並取消；拒絕 HTTP 網址與重新導向至 HTTP 的下載。
- [V] R3：下載完成後確認檔案是可播放的 MP3，再將檔案與歌曲索引存入 App 的持久儲存區；重新開啟 App 或離線時仍可使用，不將唯一音檔放在暫存區。
- [V] R4：匯入時讀取 ID3 歌名、演出者、專輯名稱與內嵌封面，至少涵蓋常見 ID3v2.3／v2.4 標籤；歌名缺少時顯示檔名，其他缺漏顯示「未知演出者」、「未知專輯」及預設封面，無標籤或標籤讀取失敗不應阻擋可播放音檔的匯入。
- [V] R5：音樂庫顯示歌曲封面、歌名與演出者；完整播放畫面另外顯示專輯、已播放時間與總長度，提供播放、暫停、拖曳進度及上一首／下一首控制。
- [V] R6：以音樂庫顯示順序播放，提供關閉循環、單曲循環及全部循環；關閉循環時最後一首結束即停止，單曲循環時自然播畢重播目前歌曲，全部循環時最後一首回到第一首。
- [V] R7：提供 15、30、60 分鐘睡眠定時器、剩餘時間與取消操作；採實際經過時間倒數，暫停或切歌不重設截止時間，重新選擇時長才重新計時，到期停止播放並清除定時器，優先於循環播放；App 重新啟動後不恢復先前定時器或自動播放。
- [V] R8：支援鎖定螢幕及切換 App 後持續播放與定時停止，並在系統播放資訊顯示歌名、演出者、封面與進度，提供播放／暫停及切歌控制；耳機拔除或音訊中斷時暫停，不擅自恢復播放。
- [V] R9：完成深色與暖橘色視覺設計，音樂庫右上角提供匯入入口，選曲後出現底部迷你播放器，點擊可展開完整播放器；涵蓋空音樂庫、下載中、播放中與錯誤狀態，控制項有可讀標籤並配合安全區域及系統文字大小。
- [V] R10：下載失敗、非 MP3、損毀音檔或儲存失敗時顯示清楚訊息，移除未完成檔案，不留下可點選的失敗歌曲，也不影響既有音樂庫。
- [V] R11：提供必要邏輯測試與建置／驗證說明，清楚記錄已實際通過及仍需 Xcode、模擬器或 iPhone 驗證的項目。

## Acceptance Criteria

- [ ] AC1：以完整 Xcode 建置專案並在 iPhone 模擬器開啟，可見 Jamz Player 名稱、繁體中文空音樂庫與匯入入口，沒有歌曲時不出現無效播放操作。
- [ ] AC2：從 HTTPS 匯入有效 MP3，可見下載進度與完成後的歌曲；關閉並重新開啟 App，再停用網路，仍可播放該歌曲。
- [ ] AC3：分別匯入帶有 ID3v2.3、ID3v2.4 的測試 MP3，歌名、演出者、專輯、中文文字與內嵌封面符合素材；無標籤與欄位不完整的 MP3 使用指定回退資訊且仍可播放。
- [ ] AC4：選曲、播放／暫停、拖曳進度、上一首／下一首皆能操作；迷你播放器、完整播放器與實際播放歌曲資訊保持一致。
- [ ] AC5：使用至少兩首短音檔驗證三種循環模式：關閉循環依序播放並停在最後，單曲自然播畢重播自身，全部循環從最後一首接回第一首。
- [ ] AC6：驗證 15／30／60 分鐘均設定正確截止時間，暫停及切歌不重設倒數，重選時長會重設，取消後不停止播放；以可控制時鐘測試截止邏輯，並在 iPhone 實際完成至少一次 15 分鐘鎖屏播放，到期停止且不被循環重新啟動。
- [ ] AC7：在 iPhone 鎖屏及切換 App 後音樂持續播放，系統資訊顯示正確且播放／暫停與切歌控制有效；拔除耳機或發生音訊中斷時暫停。
- [ ] AC8：分別測試 HTTP 網址、HTTPS 轉址至 HTTP、下載中取消、斷線、HTTP 錯誤、偽裝為 MP3 的內容及儲存失敗，出現適當結果且不留下不完整歌曲或破壞既有歌曲。
- [ ] AC9：在小尺寸與一般尺寸 iPhone 模擬器檢視音樂庫、匯入面板與播放器，深色／暖橘設計一致；長歌名及放大文字不遮蔽主要控制，播放與定時器按鈕可辨識。
- [ ] AC10：必要邏輯測試通過，README 包含可重現的建置與驗證步驟；尚未執行的模擬器及實機驗收維持未勾選，並標明限制。
